# Evaluation Annotation Guide

本指南用于人工构建期刊检索评测集。`PaperProfile` 可以由现有 Phase 1 分析器生成，
但期刊相关性标签必须由人工阅读论文与期刊范围后给出。

## 基本原则

- 禁止使用 DeepSeek、Agent、推荐器、检索器或 reranker 自动生成或补全 Gold 标签。
- 不把论文实际发表期刊自动加入 Gold；它只是可选的上下文信息，也不代表唯一正确答案。
- 只依据论文与期刊的主题、研究范围、方法适配度和目标学术社区判断相关性。
- 不能因为期刊的 CCF、JCR、中科院分区、Impact Factor 或声望较高而直接提高相关性等级。
- 系统给出的候选和排序不能作为标注依据，以免把系统偏差写进 Gold 数据。

## 相关性等级

Gold CSV 只记录正相关期刊，不使用 `0`：

- `3 — Highly Relevant`：主题、方法和期刊 scope 高度一致，是明显合理的投稿目标。
- `2 — Relevant`：主要方向或方法明确匹配，但 scope、目标社区或论文侧重点存在一定差异。
- `1 — Acceptable`：存在合理的投稿关系，但匹配较弱、较宽泛或依赖期刊的特定栏目。

建议每篇论文标注 5–10 个正相关期刊作为起点，例如 2–4 个等级 3、2–5 个
等级 2、0–3 个等级 1。构建器仅在总数少于 3 或多于 20 时警告，不会自动修改人工标签。

## 标注步骤

1. 查看 `profiles/<case_id>.json`，必要时对照原 PDF。
2. 从 SQLite 期刊库中查找主题与 scope 合适的期刊，并记录稳定的 journal ID。
3. 独立判断相关性等级，再填写 `annotations/gold_labels.csv`。
4. 可选地在 `paper_metadata.csv` 记录实际发表期刊，用于分析 venue leakage 和评测上下文。
5. 由另一位标注者复核边界案例、等级和 journal ID。

当前期刊库使用正整数 ID。CSV 可写 `12`，也兼容 `journal-12`；构建后统一保存为整数，
以便现有 Phase 7 evaluator 直接读取。

## 实际发表期刊

论文的实际发表期刊可能适合该论文，但不能据此推断其他期刊不相关。若该期刊未被人工标为
Gold，构建器只会发出警告，不会自动添加。标注者应根据相同的相关性标准决定是否将其纳入。
